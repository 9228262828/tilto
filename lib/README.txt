TILTO — Balance Drop
Tagline: Keep it level. Don't let it fall.
Package: com.tilto.balancegame

Add to pubspec.yaml:

dependencies:
  flutter:
    sdk: flutter
  shared_preferences: ^2.3.2

Features:
- Splash Screen
- Home Screen
- Endless Mode with 3 lives
- 60 Sec Challenge
- One Fall Mode
- Left / Right platform controls
- Falling balance pieces
- Simplified Dart-only game physics
- Progressive speed
- Score
- Landed piece count
- Perfect Balance bonuses
- Best Score per mode
- Pause / Resume
- Result Screen
- Statistics
- Haptic Feedback
- Dark Mode
- Privacy Policy
- Terms & Conditions
- Reset Progress
- SharedPreferences persistence

No Flame
No Firebase
No backend
No login
No ads
No analytics
No image/audio assets required
