## Publish with GitHub Pages

1. Create a GitHub repository.
2. Upload everything from this ZIP.
3. Keep the `docs` folder exactly as provided.
4. Open **Settings → Pages**.
5. Under **Build and deployment**, choose **Deploy from a branch**.
6. Select the main branch and `/docs`.
7. Save and wait for GitHub Pages to publish.

Your Privacy Policy URL will normally be:

`https://YOUR-GITHUB-USERNAME.github.io/YOUR-REPOSITORY/privacy.html`

Included:
- `docs/index.html`
- `docs/privacy.html`
- `docs/terms.html`
- `docs/style.css`
- `docs/.nojekyll`

The Privacy Policy matches the current offline-first TILTO build.

Update it before release if a future version adds:
- Firebase
- accounts/login
- cloud sync
- analytics or crash reporting
- advertising
- in-app purchases
- online leaderboards
- multiplayer/social features
- location access
- motion-sensor access
- other new permissions or data collection
